# 计算传播学论文 Review

这个仓库用于筛选、归档和精读计算传播学论文。当前先处理 *Information, Communication & Society*，时间范围限定为 **2026-01-01 至 2026-09-22**。超过这一范围的记录不进入本轮筛选。

## 当前结果

原工作簿共有 402 篇论文，其中 159 篇发表于本轮时间范围。完成标题摘要初筛，并在 Taylor & Francis 出版方网页逐篇核查 11 篇待定论文的方法部分后，得到：

- 明确纳入 35 篇；
- 待全文确认 0 篇；
- 排除 124 篇。

原表“推荐摘要”列的底色被保留为筛选线索：黄色表示原先判断为计算传播学，棕色表示原先不确定。黄色 10 篇在本轮全部纳入；棕色论文中 10 篇纳入、8 篇排除。未标色论文也经过复查，找到了 15 篇明确入选的漏标记录。

## 纳入标准

一篇论文要进入“明确纳入”，需要同时满足研究对象和研究方法两个条件：

1. 研究对象属于 AI、LLM、社交媒体、数字平台、算法传播、在线公共讨论等计算传播议题；
2. 方法明确使用计算文本、机器学习、网络分析、数字痕迹、大规模平台数据、计算模拟、模型审计等计算方法；
3. 与上述议题直接相关、且明确在线实施的实验也纳入。

仅讨论或批判数字技术的论文不纳入。民族志、访谈、一般质性研究和传统问卷也不纳入，即使它们讨论 AI 或社交媒体。摘要不足以判断方法时，论文进入“待全文确认”，不会凭标题直接收录。

## 主要产物

- `data/processed/Information, Communication & Society-2026-01-01至2026-09-22-裁剪.xlsx`：从原工作簿裁出 2026 年范围内的 159 篇，保留原字段和底色。
- `outputs/ICS-2026-计算传播学精选.xlsx`：含“筛选说明”“明确纳入”“待全文确认”“完整筛选记录”四个工作表。
- `outputs/ICS-2026-计算传播学精选.csv`：35 篇明确纳入论文，便于 Git 比较和后续导入。
- `outputs/ICS-2026-计算传播学精选-汇报版.md`：面向展示的筛选摘要、方法分布和 35 篇完整清单。

- `screening/ICS-2026-fulltext-verification.md`：11 篇待定论文的人工全文核查证据、判定和链接。

## 重新生成

```bash
python3 -m pip install -r requirements.txt
python3 scripts/screen_ics.py
```

脚本以 DOI 为稳定键记录人工筛选决定。更换或补充原始工作簿后，应先检查 DOI 是否重复或缺失，再更新筛选决定。

## 全文与精读边界

本轮没有把摘要或网页浏览记录改写成“精读”。11 篇待定论文已在出版方完整网页中核查方法，但尚未将网页或 PDF 归档为物理原件，因此台账仍标为“待获取”，也没有生成页码证据。只有取得可核验的 PDF、accepted manuscript、机构库全文或保存的完整网页全文后，才建立精读笔记。受版权保护的 PDF 默认只放在本地 `literature/papers/`，不提交到公开仓库。
