# 计算传播学论文 Review

这个仓库用于筛选、归档和精读计算传播学论文。当前先处理 *Information, Communication & Society*，时间范围限定为 **2026-01-01 至 2026-09-22**。超过这一范围的记录不进入本轮筛选。

## 当前结果

完成标题摘要初筛和出版方全文方法核查后，当前目录保留 35 篇：

- 明确相关 28 篇；
- 中等相关 7 篇。

原表“推荐摘要”列的底色被保留为筛选线索：黄色表示原先判断为计算传播学，棕色表示原先不确定。黄色 10 篇在本轮全部纳入；棕色论文中 10 篇纳入、8 篇排除。未标色论文也经过复查，找到了 15 篇明确入选的漏标记录。

公开目录按论文逐篇呈现。每篇包括中英文标题、资料中已有的作者与机构、日期、DOI、中英文摘要、核心方法和资料实施过程。研究设计与方法紧接中文摘要，英文摘要随后列出。原始资料缺少的字段直接省略，不使用占位文字。明确相关论文列在前面，7 篇中等相关论文单独放在末尾。

## 纳入标准

一篇论文要进入“明确纳入”，需要同时满足研究对象和研究方法两个条件：

1. 研究对象属于 AI、LLM、社交媒体、数字平台、算法传播、在线公共讨论等计算传播议题；
2. 方法明确使用计算文本、机器学习、网络分析、数字痕迹、大规模平台数据、计算模拟、模型审计等计算方法；
3. 与上述议题直接相关、且明确在线实施的实验也纳入。

仅讨论或批判数字技术的论文不纳入。民族志、访谈、一般质性研究和传统问卷也不纳入，即使它们讨论 AI 或社交媒体。问卷、经验抽样或一般统计为主的研究放入中等相关；只有直接操控在线传播材料或传播环境的实验，才按实验例外进入明确相关。论文的研究问题和主要发现按摘要介绍；35 篇纳入论文的方法均回到 Taylor & Francis 全文核对，方法说明不靠标题或摘要标签推断。


## 主要产物

- `data/processed/Information, Communication & Society-2026-01-01至2026-09-22-裁剪.xlsx`：从原工作簿裁出 2026 年范围内的 159 篇，保留原字段和底色。
- `outputs/ICS-2026-计算传播学精选.xlsx`：含“筛选说明”“明确纳入”“待全文确认”“完整筛选记录”四个工作表。
- `outputs/ICS-2026-计算传播学精选.csv`：35 篇精选论文，含全文核对后的核心方法与资料实施说明，便于 Git 比较和后续导入。
- `outputs/ICS-2026-计算传播学精选-汇报版.md`：公开论文目录；逐篇汇集双语标题、双语摘要、作者和具体方法，并将中等相关论文单列在末尾。
- `screening/ICS-2026-screening-log.csv`：159 篇的逐条判断及理由。
- `screening/ICS-2026-fulltext-verification.md`：初筛阶段 11 篇待定论文的人工全文核查记录、判定和链接。

## 重新生成

```bash
python3 -m pip install -r requirements.txt
python3 scripts/screen_ics.py
```

脚本以 DOI 为稳定键记录人工筛选决定。更换或补充原始工作簿后，应先检查 DOI 是否重复或缺失，再更新筛选决定。

## 全文与精读边界

本轮已经在出版方完整网页中核对 35 篇纳入论文的方法部分，但这项核对不等同于逐篇精读。尚未取得 PDF 或保存完整网页的论文仍在台账中标为“待获取”，也不生成页码证据。只有取得可核验的 PDF、accepted manuscript、机构库全文或保存的完整网页全文后，才建立精读笔记。受版权保护的 PDF 默认只放在本地 `literature/papers/`，不提交到公开仓库。
