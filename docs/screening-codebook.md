# 计算传播学筛选口径

## 判断单位

以单篇论文为判断单位。发布日期采用原工作簿的“发布日期”，本轮只处理 2026-01-01 至 2026-09-22。

## 两道门槛

### 议题门槛

论文需要直接研究数字传播对象，例如 AI 或 LLM 的传播表现、社交媒体内容与互动、数字平台和算法、在线政治传播、虚假信息、数字广告、平台治理中的可计算行为数据。

“出现 AI、算法或平台字样”本身不构成纳入理由。论文仍需通过方法门槛。

### 方法门槛

以下方法可以构成纳入依据：

- 计算文本分析：主题模型、词嵌入、自动分类、情感分析、LLM 辅助编码等；
- 网络与扩散分析：社会网络、二部网络、动态网络、跨平台关系和传播路径；
- 数字痕迹与平台数据：API、数据捐赠、被动浏览记录、广告库、平台行为日志；
- 计算模拟和模型审计：基于代理的模拟、算法或语言模型审计；
- 大规模数字行为数据建模；
- 与计算传播问题直接相关、并明确在线实施的实验。

统计模型本身不自动算作计算方法。用传统问卷收集数据，再做回归、结构方程或潜在类别分析，仍按传统调查处理。人工内容分析只有在同时使用可核验的平台数字痕迹、计算采集或其他计算步骤时，才结合具体设计判断。

## 排除规则

- 纯理论、概念、政策或规范讨论；
- 批判性分析、民族志、访谈和一般质性内容分析；
- 传统横截面调查、面板调查、量表开发和一般统计检验；
- 只讨论数字技术社会影响，但没有计算方法的论文；
- 与传播问题关系很弱的纯技术研究。

## 待全文确认

下列情况不直接纳入，也不草率排除：

- 原表没有摘要，标题又无法确定方法；
- 摘要只说“分析平台数据”，没有说明数据取得和分析过程；
- 实验研究没有说明是否在线实施；
- 只明确了爬虫采集，未说明后续是否使用计算分析。

待确认论文应在取得全文后填写数据来源、采集方式、分析技术和实验场景，再转为“纳入”或“排除”。
