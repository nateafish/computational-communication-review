# 工作流程

1. 把新收到的工作簿原样放入 `data/raw/`，不要覆盖旧文件。
2. 先按发布日期裁剪到当年 1 月 1 日至处理日。
3. 读取用户标色，但只把标色当作线索。所有记录仍需按同一口径复查。
4. 先判断议题，再判断方法。两道门槛都通过才进入“明确纳入”。
5. 摘要缺失或方法写得不清楚时，进入“待全文确认”。
6. 取得全文后，以统一 Slug 保存 PDF 和精读笔记，并更新 `reference/INDEX.md`。
7. 只有高价值论文或后续写作会实际调用的论文才建立精读笔记；不追求每篇都生成卡片。

## 文件命名

单篇论文统一使用：

```text
[FirstAuthor]-et-al-[Year]-[ShortTopic]
```

例如：

```text
literature/papers/Xu-et-al-2026-MeasuringGoogleAIOverviews.pdf
literature/notes/Xu-et-al-2026-MeasuringGoogleAIOverviews.md
```

## 状态更新

- `待获取`：只有题录和摘要，没有可核验全文；
- `全文已取得`：PDF 或完整网页全文已经保存；
- `未开始`：尚未精读；
- `精读中`：正在核对方法、结论和页码；
- `已精读`：笔记可支持后续写作与引用核查。

没有完整原文时，不填写页码证据，也不生成具体操作化结论。
